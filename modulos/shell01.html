Cada exercício é uma única linha de comando num script. A moulinette define as variáveis de ambiente (FT_USER, FT_LINE1, …) antes de o correr, por isso nunca as escrevas dentro do ficheiro.

Repara nos exemplos: quando o prompt aparece colado ao resultado (bocal$>), a saída não acaba em quebra de linha.

add_chelou.sh
Funções permitidas
Nenhuma

Escreve uma linha de comando que lê dois números das variáveis FT_NBR1 e FT_NBR2 e mostra a soma dos dois.

  • FT_NBR1 está na base '\"?! (5 símbolos: ' vale 0, \ vale 1, " vale 2, ? vale 3, ! vale 4);
  • FT_NBR2 está na base mrdoc (m = 0, r = 1, d = 2, o = 3, c = 4);
  • o resultado é mostrado na base gtaio luSnemf (13 símbolos, com um espaço no meio).
