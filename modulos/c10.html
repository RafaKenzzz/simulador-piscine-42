Cada exercício é um programa com Makefile (regras all, clean e fclean). Compara sempre o teu programa com o original: diff <(./ft_cat a b) <(cat a b) não deve mostrar nada.

As mensagens de erro vão para a saída de erro (descritor 2), não para a saída normal.

ex00 display_file

Pasta de entrega
ex00/
Ficheiros a entregar
Makefile, ft_display_file.c
Funções permitidas
close, open, read, write

Cria um programa ft_display_file que mostra na saída padrão o conteúdo do ficheiro passado como argumento, e só isso.

A pasta de entrega tem um Makefile com as regras all, clean e fclean. O executável chama-se ft_display_file.

O malloc é proibido: só podes usar um array de tamanho fixo.

Os erros aparecem na saída de erro, seguidos de uma quebra de linha:

  • sem argumentos: File name missing.;
  • com mais de um argumento: Too many arguments.;
  • se o ficheiro não puder ser lido: Cannot read file.

ex01 cat

Pasta de entrega
ex01/
Ficheiros a entregar
Makefile, ft_cat.c
Funções permitidas
close, open, read, write, strerror, basename

Cria um programa ft_cat que faz o mesmo que o comando cat do sistema. Não precisas de tratar opções.

A pasta de entrega tem um Makefile com as regras all, clean e fclean.

Podes usar a variável errno (ver man errno). Lê o man de todas as funções permitidas.

Só podes usar um array de tamanho fixo, um pouco abaixo de 30 KB. Para testar esse limite, usa o comando ulimit da shell.
