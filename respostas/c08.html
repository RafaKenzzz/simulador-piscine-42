ex00 ft.h

Cria o teu ficheiro ft.h com os protótipos de todas estas funções:

mostrar soluçãoesconder solução

Passo a passo

  1. O header só declara as funções: diz ao compilador o nome, os parâmetros e o tipo devolvido. O código fica nos .c.
  2. A proteção #ifndef FT_H / # define FT_H / #endif impede erros se o header for incluído duas vezes.
  3. Os nomes das funções ficam alinhados com tabs, na mesma coluna, como pede a Norma.

Erros comuns

  • Esquecer a proteção contra inclusão dupla.
  • Pôr o corpo das funções no header.

Casos limite que a moulinette testa

  • A moulinette inclui o ft.h num main dela e compila com as funções. Os protótipos têm de ser exatamente estes.

ex01 ft_boolean.h

Cria um ficheiro ft_boolean.h com o qual o main abaixo compile e funcione.

mostrar soluçãoesconder solução

Passo a passo

  1. Faz a lista do que o main usa e não existe: write, t_bool, TRUE, FALSE, EVEN, EVEN_MSG, ODD_MSG e SUCCESS.
  2. write precisa de <unistd.h>: como o main não o inclui, o header inclui-o.
  3. t_bool é um typedef de int; TRUE, FALSE e SUCCESS são constantes.
  4. EVEN(nbr) é uma macro com parâmetro. Os parênteses à volta de nbr protegem expressões como EVEN(argc - 1).
  5. As mensagens já levam o \n, porque o main não escreve nenhuma quebra de linha.

Erros comuns

  • Esquecer o #include <unistd.h>: o main não compila.
  • Escrever # define EVEN(nbr) nbr % 2 == 0 sem parênteses.
  • Esquecer a quebra de linha nas mensagens.

Casos limite que a moulinette testa

  • Com 0, 1 e 2 argumentos: par, ímpar, par.

ex02 ft_abs.h

Cria uma macro ABS que substitui o argumento pelo seu valor absoluto: #define ABS(Value).

mostrar soluçãoesconder solução

Passo a passo

  1. O valor absoluto é Value se for positivo e -Value se for negativo.
  2. Sem o operador ternário (proibido), multiplica-se Value por 1 ou -1: ((Value) > 0) * 2 - 1 dá 1 quando é positivo e -1 quando não é.
  3. Para 0 dá 0 * -1, que é 0.
  4. Cada uso de Value vai entre parênteses, para ABS(x + 1) funcionar.

Erros comuns

  • Escrever Value < 0 ? -Value : Value sem parênteses: ABS(x + 1) vira x + 1 < 0 ? -x + 1 : x + 1.
  • Usar o ternário, proibido pela Norma.

Casos limite que a moulinette testa

  • ABS(-42), ABS(0), ABS(x + 1) com x negativo.

ex03 ft_point.h

Passo a passo

  1. O main usa um tipo t_point com dois campos inteiros, x e y.
  2. Pela Norma, a estrutura chama-se s_point e o typedef chama-se t_point.

  • Só tem de compilar com o main do enunciado.

ex04 ft_strs_to_tab

Cria uma função que recebe um array de strings e o seu tamanho e transforma cada elemento numa estrutura:

mostrar soluçãoesconder solução

Passo a passo

  1. Reservam-se ac + 1 estruturas: uma por argumento e uma para marcar o fim.
  2. Em cada uma, size é o comprimento, str aponta para o original e copy para uma cópia nova (um ft_strdup).
  3. A última fica com str = 0.
  4. Se uma cópia falhar a meio, libertam-se as que já foram feitas e o array, e devolve-se NULL.
  5. O ft_stock_str.h está aqui só para poderes compilar: é dado pela moulinette e não se entrega.

Erros comuns

  • Pôr str a apontar para a cópia e copy para o original.
  • Esquecer o elemento final com str = 0: o ft_show_tab não sabe onde parar.
  • Reservar ac elementos em vez de ac + 1.

Casos limite que a moulinette testa

  • ac = 0 devolve um array só com o elemento final.
  • Strings vazias: size = 0 e copy é uma string vazia nova.

ex05 ft_show_tab

Cria uma função que mostra o conteúdo do array criado pelo exercício anterior.

mostrar soluçãoesconder solução

Passo a passo

  1. Percorre-se o array até ao elemento com str a 0.
  2. Para cada um: ft_putstr(str), ft_putnbr(size) e ft_putstr(copy), com uma quebra de linha depois de cada.
  3. O ft_putnbr é o do C00, copiado como função static.

Erros comuns

  • Mostrar str duas vezes em vez de copy: a moulinette altera a cópia antes de chamar a função para apanhar isto.
  • Parar quando size é 0 em vez de quando str é 0.

Casos limite que a moulinette testa

  • Testam com a cópia alterada depois do ft_strs_to_tab.
