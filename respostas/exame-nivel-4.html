level 4 fprime

Escreve um programa que recebe um int positivo e mostra os seus fatores primos, seguidos de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Começa-se em i = 2. Enquanto i dividir n, escreve-se i* e divide-se n por i; quando deixar de dividir, passa-se ao i seguinte.
  2. O menor divisor de um número é sempre primo, por isso só saem primos.
  3. Quando i * i passa de n (escrito i <= n / i), o que sobra de n, se for maior do que 1, é o último fator. É escrito sem * depois.
  4. O 1 é um caso à parte: mostra 1.

Erros comuns

  • Deixar um * no fim.
  • Testar divisores até n: com primos grandes como 804577 fica lento.

Casos limite que a moulinette testa

  • Primos (saem sozinhos), 1, potências como 1024, os exemplos do enunciado.

level 4 ft_itoa

Escreve uma função que recebe um int e o converte numa string terminada em '\0'.

mostrar soluçãoesconder solução

Passo a passo

  1. Conta-se o número de caracteres: os algarismos e, se for negativo, o -. O 0 tem um algarismo.
  2. Reserva-se esse tamanho mais 1 e preenche-se do fim para o início com n % 10.
  3. O valor passa para long, para o INT_MIN ter valor positivo.

Erros comuns

  • Falhar o INT_MIN.
  • Devolver uma string vazia para o 0.

Casos limite que a moulinette testa

  • 0, -1, INT_MAX, INT_MIN.

level 4 ft_list_remove_if

Escreve uma função ft_list_remove_if que retira da lista todos os elementos cujos dados são «iguais» aos dados de referência.

mostrar soluçãoesconder solução

Passo a passo

  1. Em vez de guardar o elemento anterior, guarda-se o endereço do ponteiro que aponta para o atual: no início é begin_list, depois é o next do elemento anterior.
  2. Para apagar, esse ponteiro passa a apontar para o seguinte e liberta-se o elemento. Assim o primeiro elemento não precisa de um caso à parte.
  3. Ao contrário do C12, aqui não há free_fct: liberta-se só o elemento, não os dados.

Erros comuns

  • Avançar depois de apagar: salta o elemento seguinte, que pode também ter de sair.
  • Libertar os dados (não é pedido).

Casos limite que a moulinette testa

  • Todos iguais, nenhum igual, iguais seguidos no início.

level 4 rev_wstr

Escreve um programa que recebe uma string e mostra as palavras por ordem inversa.

mostrar soluçãoesconder solução

Passo a passo

  1. Começa-se no fim da string. Recua-se até ao início da última palavra e escreve-se.
  2. Salta-se o espaço que a separa da anterior e repete-se; entre palavras escreve-se um espaço.
  3. Não é preciso malloc: as palavras são escritas diretamente da string original.

Erros comuns

  • Inverter as letras das palavras em vez da ordem das palavras.

Casos limite que a moulinette testa

  • Uma só palavra sai igual.

level 4 rostring

Escreve um programa que recebe uma string e a mostra depois de a rodar uma palavra para a esquerda: a primeira palavra passa para o fim e as outras ficam pela mesma ordem.

mostrar soluçãoesconder solução

Passo a passo

  1. Encontra-se a primeira palavra (depois dos espaços iniciais) e o seu tamanho.
  2. Escrevem-se as palavras seguintes com um espaço entre elas (como no epur_str).
  3. Se houve outras palavras, escreve-se um espaço; por fim, a primeira palavra.

Erros comuns

  • Deixar um espaço no fim quando só há uma palavra ("abc ").

Casos limite que a moulinette testa

  • Só uma palavra; espaços e tabs múltiplos; string vazia.

level 4 sort_int_tab

Escreve a função sort_int_tab, que ordena por ordem crescente (na própria memória) o array tab, que tem exatamente size elementos.

mostrar soluçãoesconder solução

Passo a passo

  1. Ordenação por bolha: troca-se cada par vizinho fora de ordem e recomeça-se do início.
  2. Com unsigned int, usa-se i + 1 < size em vez de i < size - 1: com size == 0, size - 1 daria 4294967295.

level 4 check_mate

Escreve um programa que recebe as linhas de um tabuleiro de xadrez e verifica se o rei está em xeque.

mostrar soluçãoesconder solução

Passo a passo

  1. Em vez de testar cada peça, olha-se a partir do rei: em cada uma das 8 direções, a primeira peça encontrada é a única que pode atacar (as outras estão tapadas).
  2. Nas 4 direções retas ataca uma torre ou uma dama; nas 4 diagonais, um bispo ou uma dama.
  3. Os peões atacam na diagonal para cima. No exemplo, o peão da linha 3 ataca o rei da linha 2: um rei é atacado por um peão que está na linha logo abaixo, numa coluna ao lado.
  4. As 8 direções saem de i de 0 a 8 (sem o 4): d = (i / 3 - 1, i % 3 - 1).

Erros comuns

  • Deixar uma peça atacar através de outra.
  • Pôr os peões a atacar para baixo: o segundo exemplo passaria a Fail.
  • Tratar letras minúsculas ou outros caracteres como peças.

Casos limite que a moulinette testa

  • Tabuleiros de 1×1 a 8×8; peças tapadas; caracteres estranhos como casas vazias.
  • Na fonte há uma nota: algumas versões do enunciado têm um exemplo em que o peão ataca para baixo. Esta solução segue os exemplos acima.
