ex00 ft_iterative_factorial

Cria uma função iterativa que devolve o fatorial do número recebido.

mostrar soluçãoesconder solução

Passo a passo

  1. O fatorial de n é 1 × 2 × … × n. Não existe para negativos (devolve 0) e 0! vale 1.
  2. Começa-se com o resultado a 1 e multiplica-se por nb, nb - 1, … até 2.
  3. Com nb igual a 0 ou 1, o ciclo não corre e devolve-se 1.

Erros comuns

  • Devolver 0 para 0!.
  • Usar recursão: o exercício pede um ciclo.

Casos limite que a moulinette testa

  • -1 dá 0, 0 dá 1, 12 dá 479001600 (o maior que cabe num int).

ex01 ft_recursive_factorial

Cria uma função recursiva que devolve o fatorial do número recebido.

mostrar soluçãoesconder solução

Passo a passo

  1. Definição recursiva: n! = n × (n - 1)!.
  2. Toda a recursão precisa de um caso que pára: aqui 0! e 1! valem 1.
  3. Os negativos são tratados antes, a devolver 0.

Erros comuns

  • Esquecer o caso de paragem: a função chama-se para sempre e o programa rebenta.

Casos limite que a moulinette testa

  • Os mesmos testes da versão iterativa.

ex02 ft_iterative_power

Cria uma função iterativa que devolve nb elevado a power.

mostrar soluçãoesconder solução

Passo a passo

  1. Multiplica-se o resultado (que começa em 1) por nb, power vezes.
  2. Com power == 0 o ciclo não corre: devolve 1, também para 0 ^ 0.

Erros comuns

  • Devolver 0 para 0 ^ 0.
  • Começar o resultado em nb e multiplicar power vezes: dá uma potência a mais.

Casos limite que a moulinette testa

  • Base negativa: (-2) ^ 3 dá -8.
  • power negativo dá 0.

ex03 ft_recursive_power

Cria uma função recursiva que devolve nb elevado a power.

mostrar soluçãoesconder solução

Passo a passo

  1. nb ^ power = nb × nb ^ (power - 1), até power == 0, que vale 1.
  2. Uma potência negativa devolve 0, como na versão iterativa.

Erros comuns

  • Não tratar power negativo: a recursão nunca chega a 0.

Casos limite que a moulinette testa

  • Os mesmos testes da versão iterativa.

ex04 ft_fibonacci

Cria uma função ft_fibonacci que devolve o elemento de índice index da sequência de Fibonacci, com o primeiro elemento no índice 0.

mostrar soluçãoesconder solução

Passo a passo

  1. F(0) = 0, F(1) = 1 e, a partir daí, cada termo é a soma dos dois anteriores.
  2. Os dois primeiros casos resolvem-se com if (index < 2) return (index);.

Erros comuns

  • Começar a sequência em 1, 1, 2.
  • Devolver 0 para índices negativos em vez de -1.

Casos limite que a moulinette testa

  • Índice 0 dá 0, 1 dá 1, 10 dá 55, -1 dá -1.
  • Esta versão é lenta para índices perto de 40; os testes ficam abaixo disso.

ex05 ft_sqrt

Cria uma função que devolve a raiz quadrada de um número, se for inteira, ou 0 se a raiz for um número irracional.

mostrar soluçãoesconder solução

Passo a passo

  1. Testa-se i = 1, 2, 3, … à procura de i * i == nb.
  2. Pára-se quando i * i passa de nb. A condição escreve-se i <= nb / i para não transbordar: 46341 * 46341 já não cabe num int.
  3. Se nenhum i servir, a raiz não é inteira e devolve-se 0.

Erros comuns

  • Escrever i * i <= nb: com nb perto de INT_MAX, i * i transborda e o ciclo não pára (ou dá um resultado errado).
  • Testar todos os i até nb: demasiado lento para números grandes.

Casos limite que a moulinette testa

  • 2147395600 dá 46340; 2147483647 dá 0; números negativos e 0 dão 0.

ex06 ft_is_prime

Cria uma função que devolve 1 se o número recebido for primo e 0 se não for.

mostrar soluçãoesconder solução

Passo a passo

  1. Abaixo de 2 nada é primo.
  2. Testam-se os divisores de 2 até à raiz quadrada de nb: se nb = a × b, um dos dois é menor ou igual à raiz. Escrito i <= nb / i para não transbordar.
  3. Se nenhum divide, o número é primo.

Erros comuns

  • Testar divisores até nb: com 2147483647 (que é primo) demora segundos e a moulinette corta.
  • Considerar 1 primo.

Casos limite que a moulinette testa

  • 2147483647 tem de responder 1 rapidamente.
  • Negativos dão 0.

ex07 ft_find_next_prime

Cria uma função que devolve o primeiro número primo maior ou igual ao número recebido.

mostrar soluçãoesconder solução

Passo a passo

  1. Até 2, a resposta é sempre 2.
  2. A partir daí, testa-se nb, nb + 1, … com o ft_is_prime até encontrar um primo.
  3. O ft_is_prime é copiado para o ficheiro como static: cada exercício é compilado sozinho.

Erros comuns

  • Devolver o primo seguinte quando nb já é primo: 3 tem de dar 3.
  • Usar um teste de primos lento.

Casos limite que a moulinette testa

  • Negativos e 0 dão 2; 2147483640 dá 2147483647.

ex08 The Ten Queens

Cria uma função que mostra todas as maneiras de pôr dez rainhas num tabuleiro de 10 × 10 sem que nenhuma consiga atacar outra numa só jogada, e devolve o número de soluções.

mostrar soluçãoesconder solução

Passo a passo

  1. Põe-se uma rainha por coluna. rows[c] é a linha da rainha da coluna c.
  2. Numa coluna nova testa-se cada linha de 0 a 9. É segura se nenhuma rainha anterior estiver na mesma linha nem na mesma diagonal (a diferença de linhas igual à diferença de colunas).
  3. Se for segura, avança-se para a coluna seguinte. Quando as 10 colunas estão preenchidas, escreve-se a solução e conta-se 1.
  4. Ao voltar da recursão testa-se a linha seguinte: é isto o backtracking.
  5. Como as linhas são testadas por ordem crescente, as soluções saem já pela ordem do exemplo.

Erros comuns

  • Esquecer uma das diagonais.
  • Devolver o número de linhas escritas errado ou esquecer a quebra de linha em cada solução.

Casos limite que a moulinette testa

  • Existem exatamente 724 soluções: a função tem de devolver 724.
  • A primeira linha é 0257948136 e a última 9742051863.
