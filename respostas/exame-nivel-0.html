level 0 aff_a

Escreve um programa que recebe uma string e mostra o primeiro carácter a que encontrar nela, seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Primeiro trata-se o caso do número errado de argumentos: a\n e acabou.
  2. Com um argumento, avança-se até encontrar um a ou o fim. Se parou num a, escreve-se o a.
  3. Em todos os casos acaba com \n.

Erros comuns

  • Escrever só \n quando não há argumentos: aí o enunciado pede a\n.
  • Escrever todos os a em vez do primeiro.

Casos limite que a moulinette testa

  • String sem a, string vazia, nenhum argumento, dois argumentos.

level 0 aff_first_param

Escreve um programa que recebe strings como argumentos e mostra o primeiro, seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. O primeiro argumento é argv[1], que só existe se argc > 1.
  2. Mede-se e escreve-se de uma vez; depois a quebra de linha.

Erros comuns

  • Escrever argv[0] (o nome do programa).

Casos limite que a moulinette testa

  • Argumentos com espaços (entre aspas) contam como um só.

level 0 aff_last_param

Escreve um programa que recebe strings como argumentos e mostra a última, seguida de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. O último argumento é argv[argc - 1].
  2. Sem argumentos, argv[argc - 1] seria o nome do programa: por isso testa-se argc > 1.

Erros comuns

  • Mostrar o nome do programa quando não há argumentos.

Casos limite que a moulinette testa

  • Um só argumento: é o primeiro e o último.

level 0 aff_z

Escreve um programa que recebe uma string e mostra o primeiro carácter z que encontrar nela, seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Lê o enunciado até ao fim: com z, sem z e com o número errado de argumentos, a saída é sempre z\n.
  2. A solução mais simples é escrever z\n e acabar. Procurar o z também está certo, mas dá o mesmo resultado.

Erros comuns

  • Escrever só \n quando não há z (isso é o aff_a).

Casos limite que a moulinette testa

  • Todos os casos dão z\n.

level 0 ft_countdown

Escreve um programa que mostra todos os algarismos por ordem decrescente, seguidos de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Começa em '9' e desce até '0'; no fim, \n.

Erros comuns

  • Esquecer a quebra de linha (ao contrário do ft_print_numbers, aqui é pedida).

Casos limite que a moulinette testa

  • Saída exata: 9876543210\n.

level 0 ft_print_numbers

Escreve uma função que mostra todos os algarismos por ordem crescente.

mostrar soluçãoesconder solução

Passo a passo

  1. É uma função, não um programa: não há main.
  2. Escreve de '0' a '9', sem quebra de linha.

Erros comuns

  • Entregar com main: o examshell compila com o main dele e dá erro de duplicação.

Casos limite que a moulinette testa

  • Saída exata: 0123456789.

level 0 hello

Escreve um programa que mostra Hello World! seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Um só write com os 13 bytes: as 12 letras e sinais e o \n.

Erros comuns

  • Contar mal os bytes do write.
  • Esquecer o ! ou a maiúscula do W.

Casos limite que a moulinette testa

  • Comparação exata com Hello World!\n.

level 0 maff_alpha

Escreve um programa que mostra o alfabeto com as letras pares em maiúscula e as ímpares em minúscula, seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Contando a partir de 0, as letras nas posições ímpares (b, d, f, …) saem em maiúscula.
  2. A letra na posição i é 'a' + i ou 'A' + i.

Erros comuns

  • Começar com A maiúsculo: o exemplo começa em a.

Casos limite que a moulinette testa

  • Saída exata do exemplo.

level 0 maff_revalpha

Escreve um programa que mostra o alfabeto ao contrário, com as letras pares em maiúscula e as ímpares em minúscula, seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. A letra na posição i (a contar do z) é 'z' - i; nas posições ímpares usa-se 'Z' - i.

Erros comuns

  • Alternar ao contrário (ZyXw…).

Casos limite que a moulinette testa

  • Saída exata do exemplo.
