level 5 brackets

Escreve um programa que recebe um número indefinido de strings. Para cada uma, mostra OK seguido de uma quebra de linha se os parênteses estiverem bem fechados, ou Error seguido de uma quebra de linha se não estiverem.

mostrar soluçãoesconder solução

Passo a passo

  1. Uma pilha guarda os parênteses abertos.
  2. Ao fechar, o parêntese do topo tem de ser o do mesmo tipo; se for, sai da pilha. Se a pilha estiver vazia ou for de outro tipo, é Error.
  3. No fim, a pilha tem de estar vazia.
  4. Como só o write é permitido, a pilha é um array: com 131072 posições cabe qualquer argumento que a shell aceite.

Erros comuns

  • Contar só o número de abertos e fechados: ([)] tem os números certos mas está errado.
  • Esquecer que a string vazia dá OK.

Casos limite que a moulinette testa

  • Strings sem parênteses, vazias, com fechos a mais, com aberturas a mais.

level 5 brainfuck

Escreve um interpretador de Brainfuck. O código vem no primeiro parâmetro e é sempre válido, com no máximo 4096 operações.

mostrar soluçãoesconder solução

Passo a passo

  1. A memória é reservada com malloc e posta a zero à mão (o calloc não está nas funções permitidas).
  2. O ponteiro de dados (p) e o ponteiro de código (c) andam separados.
  3. Para os saltos, procura-se o parêntese correspondente contando os encaixados: ft_jump anda numa direção e soma ou subtrai à profundidade em cada [ e ].
  4. Depois de cada operador, o código avança uma posição; depois de um salto, fica no carácter a seguir ao parêntese.

Erros comuns

  • Saltar para o primeiro ] em vez do correspondente, com ciclos encaixados.
  • Usar char com sinal para a memória: 255 + 1 tem de dar 0.

Casos limite que a moulinette testa

  • Os dois exemplos do enunciado; ciclos encaixados.

level 5 ft_itoa_base

Escreve uma função que converte um inteiro numa string terminada em '\0', na base pedida, e devolve-a num array reservado com malloc.

mostrar soluçãoesconder solução

Passo a passo

  1. Em base 10 com um negativo, trabalha-se com o valor positivo e põe-se o - à frente.
  2. Nas outras bases, o int é convertido para unsigned int: -1 em base 16 dá FFFFFFFF.
  3. Conta-se o número de algarismos, reserva-se o tamanho exato e preenche-se do fim para o início.

Erros comuns

  • Pôr um - em bases que não são 10.
  • Usar letras minúsculas.

Casos limite que a moulinette testa

  • 0, INT_MIN em base 10 e em base 16, base 2 e base 16.

level 5 options

Escreve um programa que recebe um número indefinido de argumentos que podem ser opções, e escreve na saída padrão uma representação dessas opções como grupos de bytes, seguida de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Para cada letra de cada opção, acende-se o bit da sua posição: opts |= 1u << (letra - 'a').
  2. Um h mostra a ajuda e um carácter fora de a–z dá Invalid Option (o primeiro que aparecer decide).
  3. No fim, escrevem-se os 32 bits do mais significativo para o menos, com um espaço a cada 8 e uma quebra de linha no fim.

Erros comuns

  • Escrever os bits do menos para o mais significativo.
  • Esquecer o espaço entre grupos ou pôr um espaço a mais no fim.

Casos limite que a moulinette testa

  • Os exemplos do enunciado; opções repetidas (-a -a) acendem o mesmo bit.

level 5 print_memory

Escreve uma função que recebe (const void *addr, size_t size) e mostra a memória como no exemplo.

mostrar soluçãoesconder solução

Passo a passo

  1. É o ft_print_memory do C02 sem a coluna do endereço: 16 bytes por linha, dois algarismos hexadecimais por byte e um espaço a cada 2 bytes.
  2. Na última linha, as posições sem bytes levam espaços, para alinhar a coluna dos caracteres.
  3. Os caracteres não imprimíveis aparecem como ..

Erros comuns

  • Esquecer o alinhamento da última linha.
  • Mostrar o endereço (aqui não é pedido).

Casos limite que a moulinette testa

  • O exemplo do enunciado (40 bytes); size múltiplo de 16; size 0.

level 5 rpn_calc

Escreve um programa que recebe como primeiro argumento uma string com uma expressão em notação polaca inversa (RPN), a calcula e mostra o resultado seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Usa-se uma pilha: cada número entra no topo; cada operador tira os dois do topo (primeiro sai o 2.º operando, depois o 1.º) e põe lá o resultado.
  2. Um elemento é um número se for um sinal opcional seguido só de algarismos; um operador é um destes cinco caracteres sozinho. Qualquer outra coisa é Error.
  3. Também é Error: um operador com menos de dois valores na pilha, uma divisão ou resto por zero, ou, no fim, mais (ou menos) do que um valor na pilha.
  4. A pilha nunca tem mais valores do que a string tem caracteres, por isso reserva-se esse tamanho.

Erros comuns

  • Trocar a ordem dos operandos em -, / e %: 5 2 - dá 3, não -3.
  • Aceitar 1 2 3 4 + (sobram valores na pilha).
  • Não tratar a divisão por zero.

Casos limite que a moulinette testa

  • Números negativos como operandos (-3), divisão por zero, string vazia, operadores colados a números (1 2+).
