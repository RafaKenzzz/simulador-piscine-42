level 2 alpha_mirror

Escreve um programa alpha_mirror que recebe uma string e a mostra trocando cada letra pela letra oposta no alfabeto, seguida de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. A letra oposta de c é 'a' + ('z' - c): a distância até ao z passa a ser a distância a partir do a.
  2. O mesmo com A e Z para as maiúsculas. O resto fica igual.

Erros comuns

  • Calcular 'z' - c e esquecer de somar 'a'.

level 2 is_power_of_2

Escreve uma função que diz se um número é uma potência de 2.

mostrar soluçãoesconder solução

Passo a passo

  1. Em binário, uma potência de 2 tem um só bit a 1 (8 é 1000).
  2. n - 1 troca esse bit por 0 e põe a 1 todos os bits abaixo (0111). Por isso n & (n - 1) é 0 só para as potências de 2.
  3. O 0 é exceção: 0 & (0 - 1) também dá 0, mas 0 não é potência de 2.

Erros comuns

  • Esquecer o caso do 0.
  • Dividir por 2 com um ciclo e testar mal o 1 (que é 2^0).

Casos limite que a moulinette testa

  • 0 dá 0; 1 dá 1; 2147483648 dá 1.

level 2 print_bits

mostrar soluçãoesconder solução

Passo a passo

  1. Do bit 7 (o da esquerda) ao 0: (octet >> i) & 1 dá o bit i.
  2. Escreve-se '0' + bit. Os zeros à esquerda também saem: são sempre 8 caracteres.

  • 0 dá 00000000; 255 dá 11111111.

level 2 reverse_bits

Escreve uma função que recebe um byte, o inverte bit a bit (como no exemplo) e devolve o resultado.

mostrar soluçãoesconder solução

Passo a passo

  1. Repete-se 8 vezes: tira-se o bit da direita de octet (octet & 1) e põe-se à direita de res, que antes anda uma posição para a esquerda.
  2. O primeiro bit tirado acaba na posição mais à esquerda.

Erros comuns

  • Trocar as duas metades (isso é o swap_bits).
  • Fazer só 7 voltas.

Casos limite que a moulinette testa

  • 0x26 (00100110) dá 0x64 (01100100); 1 dá 128.

level 2 swap_bits

Escreve uma função que recebe um byte, troca as duas metades (como no exemplo) e devolve o resultado.

mostrar soluçãoesconder solução

Passo a passo

  1. A metade de cima desce 4 posições (octet >> 4) e a de baixo sobe 4 (octet << 4); junta-se com |.
  2. Como o resultado é unsigned char, os bits que sobem para lá do 8.º desaparecem.

Erros comuns

  • Usar int no meio sem converter: o valor devolvido continua a ser cortado para 8 bits, mas convém perceber porquê.

Casos limite que a moulinette testa

  • 0x41 dá 0x14; 0xF0 dá 0x0F.

level 2 wdmatch

mostrar soluçãoesconder solução

Passo a passo
