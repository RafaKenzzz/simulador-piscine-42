ex00 libft

Cria a tua biblioteca, chamada libft.a.

mostrar soluçãoesconder solução

Passo a passo

  1. gcc -c compila cada .c para um .o, sem criar um executável (não há main).
  2. ar rc libft.a junta os .o numa biblioteca: r acrescenta ou substitui, c cria o arquivo se não existir.
  3. ranlib cria o índice da biblioteca, que permite ao compilador encontrar as funções.
  4. Os ficheiros são escritos pelo nome, sem *.c: assim nada que esteja a mais na pasta entra na biblioteca.

Erros comuns

  • Compilar sem -c: o gcc tenta criar um programa e falha por não haver main.
  • Esquecer o ranlib (em alguns sistemas a ligação falha sem índice).
  • Esquecer as flags -Wall -Wextra -Werror.

Casos limite que a moulinette testa

  • A moulinette compila um main dela com -L. -lft e chama as cinco funções.

ex01 Makefile

Cria o Makefile que compila a biblioteca libft.a:

mostrar soluçãoesconder solução

Passo a passo

  1. OBJS = $(SRCS:.c=.o) troca a extensão de cada fonte: os .o ficam na mesma pasta dos .c.
  2. A regra $(NAME): $(OBJS) só corre se algum .o for mais recente do que a biblioteca. Assim, um segundo make não faz nada.
  3. A regra %.o: %.c compila cada .c com -I includes, para encontrar o ft.h. Só recompila os .c que mudaram.
  4. all é a primeira regra, por isso é a que o make corre sem argumentos.
  5. .PHONY diz que all, clean, fclean e re não são ficheiros.
  6. As fontes estão escritas uma a uma: o enunciado avisa contra os wildcards (*.c).

Erros comuns

  • Usar espaços em vez de tabs antes dos comandos: missing separator.
  • Usar $(wildcard srcs/*.c) ou *.c.
  • Pôr @ antes dos comandos: o enunciado pede que sejam mostrados.
  • Um re que não volta a compilar tudo.

Casos limite que a moulinette testa

  • make duas vezes seguidas: a segunda não compila nada.
  • Alterar um .c e correr make: só esse é recompilado.

ex02 ft_split

Cria uma função que divide uma string usando como separador cada carácter de charset.

mostrar soluçãoesconder solução

Passo a passo

  1. É o mesmo exercício do C07. Conta-se o número de palavras, reserva-se o array (+1 para o 0) e copia-se cada palavra.
  2. Uma palavra começa num carácter que não é separador e que vem depois de um separador ou no início.

Erros comuns

  • Strings vazias entre separadores seguidos.
  • Esquecer o 0 no fim.

Casos limite que a moulinette testa

  • String vazia, só separadores, charset vazio.
