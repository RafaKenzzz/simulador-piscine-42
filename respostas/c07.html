ex00 ft_strdup

Reproduz o comportamento da função strdup (man strdup).

mostrar soluçãoesconder solução

Passo a passo

  1. Mede-se src e reservam-se len + 1 bytes: o + 1 é para o '\0'.
  2. Se o malloc devolver NULL, devolve-se NULL.
  3. Copia-se tudo, incluindo o '\0', e devolve-se a cópia.

Erros comuns

  • Reservar só len bytes.
  • Não testar o retorno do malloc.

Casos limite que a moulinette testa

  • String vazia: devolve uma string nova com só o '\0'.

ex01 ft_range

Cria uma função ft_range que devolve um array de int com todos os valores entre min e max.

mostrar soluçãoesconder solução

Passo a passo

  1. O array tem max - min elementos. Esse tamanho é calculado em long: com min = INT_MIN e max = INT_MAX, a diferença não cabe num int.
  2. Reserva-se sizeof(int) * tamanho e preenche-se com min + i.

Erros comuns

  • Reservar max - min bytes em vez de max - min inteiros (esquecer o sizeof(int)).
  • Incluir o max.

Casos limite que a moulinette testa

  • min == max dá NULL; intervalos com negativos; extremos do int.

ex02 ft_ultimate_range

Cria uma função ft_ultimate_range que reserva e preenche um array de int com todos os valores entre min e max (min incluído, max excluído).

mostrar soluçãoesconder solução

Passo a passo

  1. É o ft_range com o array devolvido através de *range.
  2. range é o endereço de um ponteiro de quem chama; escrever em *range muda esse ponteiro.
  3. Para escrever no array usa-se (*range)[i]: os parênteses são obrigatórios, porque *range[i] seria *(range[i]).

Erros comuns

  • Escrever *range[i].
  • Esquecer o *range = NULL quando min >= max.

Casos limite que a moulinette testa

  • Testam o valor devolvido e o ponteiro nos três casos: normal, vazio e erro.

ex03 ft_strjoin

Escreve uma função que junta todas as strings de strs, separadas por sep.

mostrar soluçãoesconder solução

Passo a passo

  1. Calcula-se o tamanho final: a soma dos tamanhos das strings, mais size - 1 separadores, mais 1 para o '\0'.
  2. Reserva-se tudo de uma vez.
  3. Copia-se cada string e, entre elas (não depois da última), o separador. A função ft_append devolve o novo fim, para não ter de medir o resultado outra vez.

Erros comuns

  • Pôr um separador depois da última string.
  • Com size == 0, devolver NULL ou uma string literal "" (que não pode ser libertada).

Casos limite que a moulinette testa

  • size 0 e 1; strings vazias; separador vazio.

ex04 ft_convert_base

Cria uma função que devolve o resultado da conversão da string nbr da base base_from para a base base_to.

mostrar soluçãoesconder solução

Passo a passo

  1. São dois passos: ler nbr para um número (um ft_atoi_base) e escrever esse número na outra base (um ft_itoa_base).
  2. Como cada ficheiro só pode ter 5 funções, as funções auxiliares ficam no ft_convert_base2.c. Os protótipos delas são declarados no início do ft_convert_base.c.
  3. O número é guardado num long: assim o valor positivo de -2147483648 cabe durante a conversão.
  4. Para escrever, calcula-se primeiro quantos caracteres são precisos, reserva-se o tamanho exato e preenche-se do fim para o início.
  5. As duas bases são validadas com as regras do ft_atoi_base (sem +, - e espaços em branco).

Erros comuns

  • Converter através de um int: falha com -2147483648.
  • Mostrar -0 para zero com sinal negativo.
  • Esquecer que as strings podem não ser modificáveis e tentar escrever nelas.

Casos limite que a moulinette testa

  • "-0" dá "0"; INT_MAX e INT_MIN; bases inválidas dão NULL.

ex05 ft_split

Cria uma função que divide uma string em várias, usando como separador cada carácter da string charset.

mostrar soluçãoesconder solução

Passo a passo

  1. Primeiro contam-se as palavras: começa uma palavra em cada carácter que não é separador e que vem depois de um separador (ou no início).
  2. Reserva-se o array com mais uma posição para o 0 final.
  3. Depois repete-se: saltar separadores, copiar a palavra para uma string nova, saltar a palavra.
  4. Como os separadores são saltados todos de uma vez, separadores seguidos nunca dão strings vazias.
  5. Neste exercício só o malloc é permitido, por isso não há free em caso de erro.

Erros comuns

  • Criar strings vazias com separadores seguidos ou no início e no fim.
  • Esquecer o 0 no fim do array.
  • Modificar a string original (por exemplo, pôr '\0' no lugar dos separadores).

Casos limite que a moulinette testa

  • String vazia ou só com separadores: array só com o 0.
  • charset vazio: a string inteira é uma palavra.
