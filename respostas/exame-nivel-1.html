level 1 first_word

Escreve um programa que recebe uma string e mostra a primeira palavra, seguida de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Saltam-se os espaços e tabs do início.
  2. Escreve-se carácter a carácter até ao próximo espaço, tab ou fim.
  3. Pontuação faz parte da palavra: lorem,ipsum é uma só.

Erros comuns

  • Esquecer os tabs como separadores.
  • Não saltar os espaços iniciais.

Casos limite que a moulinette testa

  • Só espaços, string vazia, dois argumentos.

level 1 repeat_alpha

Escreve um programa repeat_alpha que recebe uma string e a mostra repetindo cada letra tantas vezes quanto a sua posição no alfabeto, seguida de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Para uma letra, o número de vezes é c - 'a' + 1 (ou c - 'A' + 1 nas maiúsculas). Os outros caracteres saem uma vez.
  2. Repete-se o write desse carácter esse número de vezes.

Erros comuns

  • Esquecer as maiúsculas: A também é a 1.ª letra.
  • Repetir espaços e algarismos.

Casos limite que a moulinette testa

  • O exemplo Alex.: o x sai 24 vezes.

level 1 rot_13

Escreve um programa que recebe uma string e a mostra trocando cada letra pela que está 13 posições à frente no alfabeto.

mostrar soluçãoesconder solução

Passo a passo

  1. Converte-se a letra para a posição 0–25, soma-se 13, faz-se % 26 para dar a volta e converte-se de novo para letra.
  2. Os caracteres que não são letras ficam iguais.

Erros comuns

  • Somar 13 sem dar a volta: z passa a \x87.
  • Fazer c + 13 e só depois o módulo, com valores que já não são posições.

Casos limite que a moulinette testa

  • Letras do fim do alfabeto, maiúsculas, pontuação e algarismos.

level 1 search_and_replace

Escreve um programa search_and_replace que recebe 3 argumentos: uma string, uma letra a procurar (2.º argumento) e a letra que a substitui (3.º argumento).

mostrar soluçãoesconder solução

Passo a passo

  1. O exemplo com "art" e "zul" mostra que o 2.º e o 3.º argumentos têm de ter exatamente um carácter; senão, só a quebra de linha.
  2. Percorre-se a string e escreve-se o 3.º argumento onde estiver o 2.º; os outros caracteres saem iguais.

Erros comuns

  • Aceitar argumentos com mais de um carácter e usar só o primeiro.
  • Esquecer a quebra de linha final.

Casos limite que a moulinette testa

  • Letra inexistente: a string sai igual.
  • Espaços no fim da string mantêm-se.

level 1 ulstr

Escreve um programa que recebe uma string e troca as maiúsculas por minúsculas e vice-versa. Os outros caracteres ficam iguais.

mostrar soluçãoesconder solução

Passo a passo

  1. Minúscula: subtrai-se 32. Maiúscula: soma-se 32. O resto fica igual.

Erros comuns

  • Usar dois if separados: uma letra trocada pelo primeiro volta a ser trocada pelo segundo. É preciso else if.

Casos limite que a moulinette testa

  • Espaços duplos, algarismos e pontuação mantêm-se.
