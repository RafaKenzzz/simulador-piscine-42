ex00 ft_strcpy

Reproduz o comportamento da função strcpy (man strcpy).

mostrar soluçãoesconder solução

Passo a passo

  1. Copia-se carácter a carácter até ao '\0' de src.
  2. O '\0' também é copiado: sem ele, dest não acaba onde devia.
  3. Devolve-se dest, como o strcpy.

Erros comuns

  • Esquecer o '\0' no fim de dest.
  • Devolver src ou não devolver nada.

Casos limite que a moulinette testa

  • src vazia: dest[0] passa a '\0'.

ex01 ft_strncpy

Reproduz o comportamento da função strncpy (man strncpy).

mostrar soluçãoesconder solução

Passo a passo

  1. Copia-se no máximo n caracteres de src.
  2. Se src acabar antes de n, as posições que faltam até n são preenchidas com '\0' (está no man).
  3. Se src tiver n ou mais caracteres, dest não fica terminado em '\0'.

Erros comuns

  • Parar no '\0' de src sem preencher o resto até n.
  • Acrescentar um '\0' em dest[n]: escreve um byte a mais do que o strncpy.

Casos limite que a moulinette testa

  • n = 0 não mexe em nada.
  • A moulinette compara os n bytes de dest, não só a string.

ex02 ft_str_is_alpha

Cria uma função que devolve 1 se a string recebida só tiver letras (maiúsculas ou minúsculas), e 0 se tiver qualquer outro carácter.

mostrar soluçãoesconder solução

Passo a passo

  1. Percorre-se a string e devolve-se 0 no primeiro carácter que não cumpre a regra.
  2. Se o ciclo chegar ao '\0', todos cumpriram (ou não havia nenhum) e devolve-se 1.
  3. Uma letra está entre 'a' e 'z' ou entre 'A' e 'Z'. Os caracteres entre 'Z' e 'a' ([, \, ` ``…) não são letras.

Erros comuns

  • Devolver 0 para a string vazia.
  • Usar <=/>= com os caracteres errados nas fronteiras.

Casos limite que a moulinette testa

  • A string vazia devolve 1.

ex07 ft_strupcase

Cria uma função que passa todas as letras a maiúsculas. Deve devolver str.

mostrar soluçãoesconder solução

Passo a passo

  1. Na tabela ASCII, uma minúscula e a maiúscula correspondente estão sempre a 32 de distância.
  2. Só se subtrai 32 às letras entre 'a' e 'z'; tudo o resto fica igual.

Erros comuns

  • Subtrair 32 a todos os caracteres: os algarismos e a pontuação estragam-se.

Casos limite que a moulinette testa

  • Strings com algarismos, pontuação e letras já maiúsculas.

ex09 ft_strcapitalize

Cria uma função que põe em maiúscula a primeira letra de cada palavra e todas as outras letras em minúscula.

mostrar soluçãoesconder solução

Passo a passo

  1. Primeiro passa-se tudo a minúsculas.
  2. Depois, uma letra fica maiúscula se estiver no início da string ou se o carácter antes dela não for letra nem algarismo.
  3. 42mots não muda: o m vem depois de um algarismo, por isso não está no início de uma palavra.
  4. quarante-deux passa a Quarante-Deux: o - separa palavras.

Erros comuns

  • Considerar só o espaço como separador: +, - e ; também separam.
  • Pôr 42Mots, esquecendo que os algarismos fazem parte da palavra.
  • Não passar a minúsculas o resto da palavra (oLA tem de dar Ola).

Casos limite que a moulinette testa

  • O exemplo do enunciado é o primeiro teste.
  • Uma letra isolada (a b) fica maiúscula.

ex10 ft_strlcpy

Reproduz o comportamento da função strlcpy (man strlcpy).

mostrar soluçãoesconder solução

Passo a passo

  1. size é o tamanho total do buffer dest. Cabem size - 1 caracteres mais o '\0'.
  2. Copia-se até ao fim de src ou até size - 1 caracteres, e termina-se com '\0'.
  3. Com size == 0 não se escreve nada.
  4. Devolve-se sempre o tamanho de src. Se for >= size, quem chama sabe que a cópia ficou cortada.

Erros comuns

  • Devolver o número de caracteres copiados em vez do tamanho de src.
  • Escrever o '\0' quando size é 0.
  • Calcular size - 1 com size == 0: em unsigned int dá 4294967295 e a cópia não pára.

Casos limite que a moulinette testa

  • size 0, 1, igual e maior do que o tamanho de src.

ex11 ft_putstr_non_printable

Cria uma função que mostra uma string. Os caracteres não imprimíveis são mostrados em hexadecimal (com letras minúsculas), precedidos de uma barra invertida.

mostrar soluçãoesconder solução

Passo a passo

  1. Imprimíveis: códigos de 32 a 126. Os restantes saem como \ e dois algarismos hexadecimais.
  2. Os dois algarismos são c / 16 e c % 16, usados como índices da string "0123456789abcdef".
  3. O carácter é lido como unsigned char: os bytes acima de 127 (acentos em UTF-8) dariam valores negativos num char.

Erros comuns

  • Mostrar \a em vez de \0a: são sempre dois algarismos.
  • Usar maiúsculas (\0A).
  • Esquecer os bytes acima de 127.

Casos limite que a moulinette testa

  • \n dá \0a, o tab dá \09, o 127 dá \7f.
  • Um é em UTF-8 são dois bytes: \c3\a9.

ex12 ft_print_memory

Cria uma função que mostra uma zona de memória. Cada linha tem três colunas separadas por um espaço:

mostrar soluçãoesconder solução

Passo a passo

  1. Trabalha-se com unsigned char *, para ler um byte de cada vez sem sinal.
  2. Cada linha começa no byte off (0, 16, 32…). O endereço desse byte é escrito com 16 algarismos hexadecimais.
  3. A coluna do meio tem sempre 16 posições: dois algarismos por byte, ou dois espaços quando o byte não existe (última linha). Depois de cada posição ímpar vem um espaço.
  4. A coluna da direita mostra só os bytes que existem.
  5. A função ft_put_hex escreve qualquer número com uma largura fixa: 16 para o endereço e 2 para cada byte.
  6. Dividido em quatro funções, nenhuma passa das 25 linhas.

Erros comuns

  • Não alinhar a última linha: sem espaços na coluna do meio, a coluna dos caracteres fica fora do sítio.
  • Usar char em vez de unsigned char: os bytes acima de 127 dão algarismos errados.
  • Escrever o endereço sem zeros à esquerda.
  • Mostrar uma linha vazia quando size é 0.

Casos limite que a moulinette testa

  • O exemplo do enunciado, com o '\0' final incluído no tamanho.
  • size múltiplo de 16 e não múltiplo; size menor do que 16.
