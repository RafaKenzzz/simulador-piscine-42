level 3 add_prime_sum

Escreve um programa que recebe um inteiro positivo e mostra a soma de todos os números primos menores ou iguais a ele, seguida de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. O ft_atoi só aceita algarismos: um -, letras ou uma string vazia dão 0, que é o que o enunciado pede para argumentos inválidos.
  2. Soma-se cada n de 2 até ao número que seja primo (teste até à raiz quadrada).
  3. O resultado é escrito com um ft_putnbr (o printf não está nas funções permitidas).

Erros comuns

  • Contar o 1 como primo: 5 daria 11 em vez de 10.
  • Usar printf.

Casos limite que a moulinette testa

  • 1 e 0 dão 0; 2 dá 2.

level 3 epur_str

Escreve um programa que recebe uma string e a mostra com exatamente um espaço entre palavras, sem espaços nem tabs no início ou no fim, seguida de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Repete-se: saltar espaços e tabs; se ainda houver uma palavra e não for a primeira, escrever um espaço; escrever a palavra.
  2. Assim os espaços só aparecem entre duas palavras, nunca nas pontas.

Erros comuns

  • Deixar um espaço no fim quando a string acaba em espaços.
  • Tratar só espaços e esquecer os tabs.

Casos limite que a moulinette testa

  • Só espaços dá \n.

level 3 ft_atoi_base

Escreve uma função que converte a string str (numa base N <= 16) para um inteiro em base 10 e o devolve.

mostrar soluçãoesconder solução

Passo a passo

  1. ft_value dá o valor de um algarismo (0–15) ou -1 se não for algarismo.
  2. Um algarismo só é válido se for menor do que a base: na base 4, o 5 termina a leitura.
  3. Acumula-se com resultado * base + valor.

Erros comuns

  • Aceitar espaços ou + no início: este enunciado não os menciona (é diferente do ft_atoi_base do C04).
  • Esquecer as maiúsculas.

Casos limite que a moulinette testa

  • "12fdb3" e "12FDB3" em base 16; "-101" em base 2 dá -5.

level 3 ft_range

Escreve a função ft_range, que reserva com malloc um array de inteiros, o preenche com os valores seguidos de start até end (incluindo os dois!) e devolve um ponteiro para o primeiro.

mostrar soluçãoesconder solução

Passo a passo

  1. O tamanho é a distância entre os dois mais 1; o passo é +1 se end for maior e -1 se for menor.
  2. Ao contrário do ft_range do C07, aqui o end está incluído e a sequência pode descer.

Erros comuns

  • Excluir o end.
  • Não tratar o caso em que start > end.

Casos limite que a moulinette testa

  • Os quatro exemplos do enunciado.

level 3 lcm

Escreve uma função que recebe dois unsigned int e devolve o mínimo múltiplo comum (MMC, ou LCM em inglês).

mostrar soluçãoesconder solução

Passo a passo

  1. O máximo divisor comum calcula-se com o algoritmo de Euclides: troca-se (a, b) por (b, a % b) até b ser 0.
  2. Faz-se a / mdc * b em vez de a * b / mdc: dividir primeiro evita transbordar.

Erros comuns

  • Calcular a * b primeiro com números grandes.
  • Não tratar o 0.

Casos limite que a moulinette testa

  • (0, 5) dá 0; (4, 6) dá 12; (7, 13) dá 91.

level 3 pgcd

Escreve um programa que recebe duas strings que representam dois inteiros estritamente positivos que cabem num int.

mostrar soluçãoesconder solução

Passo a passo

  1. Algoritmo de Euclides: enquanto b não for 0, (a, b) passa a (b, a % b). No fim, a é o MDC.

Erros comuns

  • Testar todos os divisores a partir do menor número: funciona, mas é mais lento e mais comprido.

Casos limite que a moulinette testa

  • Números primos entre si dão 1.

level 3 print_hex

Escreve um programa que recebe um número positivo (ou zero) em base 10 e o mostra em base 16 (com letras minúsculas), seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Converte-se o argumento com um ft_atoi próprio.
  2. Depois é um ft_putnbr em base 16: primeiro n / 16 (recursão) e depois o símbolo "0123456789abcdef"[n % 16].

Erros comuns

  • Usar maiúsculas.
  • Não mostrar nada para o 0 (tem de mostrar 0).

Casos limite que a moulinette testa

  • 0 dá 0; 2147483647 dá 7fffffff.

level 3 rstr_capitalizer

Escreve um programa que recebe uma ou mais strings e, em cada uma, põe em maiúscula a última letra de cada palavra e o resto em minúsculas; depois mostra o resultado de cada uma seguido de uma quebra de linha.

mostrar soluçãoesconder solução

Passo a passo

  1. Para cada carácter: passa-se a minúscula; se for uma letra e o carácter seguinte for espaço, tab ou o fim, passa-se a maiúscula.
  2. Os espaços e tabs saem tal como estão (não se normalizam).

Erros comuns

  • Pôr em maiúscula o último carácter mesmo que não seja letra.
  • Juntar todos os argumentos numa só linha.

Casos limite que a moulinette testa

  • Uma letra sozinha (E) fica maiúscula; algarismos ficam iguais.

mostrar soluçãoesconder solução
